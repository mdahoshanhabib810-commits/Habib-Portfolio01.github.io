1. PROJECT DESCRIPTION
========================================

This is my personal portfolio website.

The website represents my skills, personal
information, projects and contact details.

The design uses a clean white background
with cyan blue colors and modern animations.

========================================
2. PROJECT FILES
========================================

Main structure of the website.

style.css
Website design, colors, layout,
animations and responsive styling.

script.js
Mobile menu, typing animation,
back to top button and contact form.

IMG_0708.jpg
My personal profile picture.

Project documentation and instructions.

========================================
4. HOW TO RUN THE PROJECT
========================================

Step 1:
Open Visual Studio Code.

Step 2:
Open the Habib-Portfolio folder.

Step 3:
Make sure all project files are
inside the same folder.

Step 4:
Check that your profile picture
is named IMG_0708.jpg.

Step 5:
Open index.html.

Step 6:
Right click and select
"Open with Live Server".

Step 7:
Your portfolio website will
open in the browser.
